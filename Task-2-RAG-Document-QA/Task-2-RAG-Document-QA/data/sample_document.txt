
DATHEON AI INTERNSHIP — SAMPLE DOCUMENT

This is a fictional sample document created for testing a
Retrieval-Augmented Generation (RAG) application.

PROJECT DETAILS

The project name is Smart Library Assistant.
The project uses Python to answer questions about library
documents and book information.

TECHNOLOGY STACK

The application uses Python for programming.
LangChain manages document loading, text splitting, and retrieval.
ChromaDB stores document embeddings in a vector database.
Google Gemini generates embeddings and answers user questions.

DOCUMENT PROCESSING

PDF files are loaded page by page.
Text documents are loaded as plain text.
Long documents are divided into smaller chunks.
Each chunk retains metadata about its source document.
PDF source page numbers are included in the metadata.

QUESTION ANSWERING

When a user asks a question, the application retrieves up to
four relevant text chunks from the vector database.
The language model uses the retrieved context to produce an answer.
The application displays the source document and page numbers
when those details are available.

PROJECT OBJECTIVES

The main objective is to answer questions using the supplied
documents rather than unsupported outside information.
If the requested information is absent from the retrieved context,
the assistant should say that it could not find the answer.

SECURITY

API keys must be kept in a local environment file.
Private documents and API credentials must not be uploaded
to a public GitHub repository.
